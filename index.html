🌐 STRUKTUR JARINGAN LENGKAP - Pahami Alur Jaringan

Pahami alur jaringan dari Internet ke perangkat Anda. Ini pondasi 80% hacking jaringan.

🌐 INTERNET↓📦 MODEM / ISP↓📡 ROUTER WiFi (192.168.1.1)↓📱 HP   💻 LAPTOP   🖥️ PC   📺 TV

Kalau hacker masuk lewat Router, semua perangkat di bawahnya bisa kena. Makanya Router harus diamankan dulu!

📶

1. LAN vs WAN

LAN: Jaringan kecil, WiFi rumah/sekolah.
WAN: Jaringan besar, Internet.

🌐

2. IP Address

Alamat perangkat. Contoh: 192.168.1.1 = Router. 192.168.1.5 = HP kamu.

🧱

3. Firewall & IDS/IPS

Firewall = Satpam. IDS = Deteksi serangan. IPS = Cegah serangan otomatis.

📦

4. DNS

Buku telepon internet. Ubah google.com jadi IP. Kalau dibajak, diarahkan ke website palsu.

🔌

5. Port

Pintu layanan. 22=SSH, 80=HTTP, 443=HTTPS. Port terbuka = celah. Cek dengan Nmap.

🔐

6. HTTP vs HTTPS

HTTP: Tidak aman. HTTPS: Aman, ada gembok, data terenkripsi.

📨

7. TCP/IP & OSI

7 Layer OSI: Physical, Data Link, Network, Transport, Session, Presentation, Application.

📡

8. WiFi - WPA2/WPA3

WPA2 sudah lama, WPA3 lebih aman. Jangan pakai WEP / password lemah.

🕵️

9. Serangan Jaringan

Phishing, MITM, Sniffing, DDoS, SQL Injection, XSS. Semua dipelajari cara cegahnya.
